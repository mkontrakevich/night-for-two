# Ночь на двоих — реализация персонального ядра

## Целевое действие и этап

Два взрослых партнёра приватно выбирают интересы, темп, уровень откровенности, разрешения и исключения. Система показывает только безопасный совместный результат, создаёт одну оригинальную идею и учитывает короткий личный отклик. Этап: PR и подготовка к production. Docker CI прошёл; развёртывание и проверка двумя партнёрами ещё не проводились.

## Проверенная исходная архитектура

- Существующий `Night V2` сохраняет комнаты, игроков, приватные выборы, отклики и связь с LoveStory в PostgreSQL.
- Telegram вход находится в `❤️ Пара → 🌙 Ночь на двоих`; прежние комнаты и библиотека сохраняются для совместимости.
- Новый формат выбора помечен `version:3`, чтобы личный ИИ-сценарий не смешивался с уже начатым сеансом старого формата.

## Новая модель

| Слой | Что хранит и делает |
| --- | --- |
| Couple Preference Model | Приватные категории, уровень и темп каждого через LoveStory Learning; реакции по раундам и общий паспорт. |
| Variety Matrix | Идентификаторы практики, категории, механики, контекста, уровня и необходимого разрешения без готовых текстов. |
| Novelty Engine | Убирает недавнюю семантическую комбинацию и отвергнутую практику; понижает частоту повторявшихся направлений. |
| AI Generator | Создаёт конкретную карточку из разрешённых вариантов; независимая проверка отклоняет выход за практику, механику, контекст, уровень и смысловой повтор. |
| Приватные желания | «Хочу попробовать» хранится отдельно по участникам; другому показывается только нейтральный факт взаимного интереса. |
| Диагностика | При ошибке генерации фиксируются этап, исключение, состояние сеанса, метаданные запроса и ответа API без токенов или текста приватных ответов. |

Темп — маркер предпочтения, без минут и таймера. Уровень ограничен минимумом двух выборов. Практика исключается при запрете любого партнёра; необходимое разрешение должно быть дано обоими. Отсутствие разрешения не считается согласием. Тестовый партнёр не попадает в реальную историю и паспорт.

## Референсы и происхождение решений

- **Подтверждено в записи Couple Adventure от пользователя (22.09.2026, около 10 минут):** тематические наборы, варианты действий внутри карточки, оценка, разные направления для него и неё, сетка купонов.
- **Адаптация для «Ночи на двоих»:** многомерное пространство разновидностей и игровых механик вместо копирования каталога и текстов.
- **Материалы @juliasexpress:** конкретные материалы в этом PR не проверены; приписывать ей решение или одобрение функции нельзя.
- **Наша разработка:** раздельный темп, машинное пересечение границ, семантическая история и проверка с отказом при сомнении.

## Проверка и ограничения

Локально проверены синтаксис серверного и клиентского JS, парсинг встроенного скрипта и сценарии ядра: разные темпы, меньший уровень, пересечение разрешений, запреты, повторы и отказ аудита. Полный Docker CI прошёл на `a131cef372976aa9314d7e2331090f939f688e6f` ([запуск 35727826907](https://github.com/mkontrakevich/marins-reminder-bot/actions/runs/35727826907)). Тестовый сеанс двух партнёров через Telegram ещё нужен для подтверждения сквозного поведения. AI проверка смысла снижает риск повтора или выхода за границы, но не заменяет тестирование реальными взрослыми пользователями; при ошибке идея не показывается.
