# «Ночь на двоих — Действия»

Самостоятельный HTTPS-продукт на `/actions`. Reader остаётся доступен отдельно. Ссылки из страниц рассказа на действия добавляются после проверки всего пользовательского пути.

## Сценарий

1. После завершения романа пара открывает `/actions` в Telegram с двух устройств.
2. При создании сессии сервис ищет последний **завершённый рассказ именно этих двух пользователей** и сохраняет неизменяемый сюжетный снимок: три заголовка и кратких описания сцен (начало, середина, финал). Если такого рассказа нет, используется фиксированная «Комната №17».
3. На каждой сцене каждый приватно выбирает слова, объятие, поцелуй, контакт ладоней или пропуск. Выбор партнёра не показывается. Допустимое действие определяется более мягкой из двух границ; пропуск имеет приоритет.
4. Для персонального рассказа AI Director получает только выбранную сцену, взаимную границу и до трёх достоверных агрегированных предпочтений. Он возвращает короткое выполнимое задание. Отдельная проверка отклоняет выход за границы; при сбое используется детерминированная мягкая карточка. Итог сохраняется один раз для пары.
5. Оба отмечают завершение, после чего открывается следующая сцена. Инициатор может начать новую сессию только по окончании предыдущей.

## Граница данных

Снимок создаётся исключительно из `story_flow.history[].title/text` и финальной `story_flow.scene.title/text`. В него не копируются `reader_pages`, приватные ответы, `director_signal`, исходные сообщения, выводы бота или полный `relationshipProfile`. Контактные данные, URL и телефоны удаляются из описаний. Агрегированный контекст приходит через существующий connector (`raw_messages=false`) и используется только во время составления задания. В таблицах действий сохраняются сюжетный снимок, приватные выборы и итоговая общая карточка.

## Независимость и эксплуатация

- `/actions`, `/actions/api/*`, `/actions/health` используют собственные таблицы `night_actions_sessions`, `night_actions_choices`, `night_actions_cards` в том же PostgreSQL.
- Cloudflare Pages маршрутизирует `/actions*` через отдельную функцию и существующий gateway к изолированному origin на host port 5683.
- Создание снимка не меняет состояние Reader и не вызывает запись в базу бота.
- Важный следующий gate: `GET /actions/health` должен вернуть `{"ok":true,"product":"night_actions"}` по HTTPS. Затем нужно проверить два реальных устройства и различающиеся приватные границы, пропуск, повторную сессию и персональный сюжет.
